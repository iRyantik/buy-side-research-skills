# AI Data Center Power

本 topic 追踪 AI 数据中心电力基础设施相关研究。当前研究框架已经从“AI 用电是不是主题”推进到“哪些公司能把 data-center power / thermal / electrical demand 直接变成 revenue、orders、backlog 或 margin”。

## Current Map

- 当前最高置信结论：VRT 是最纯的 direct exposure；ETN 是更均衡的 diversified electrical comp；GEV / CAT / GNRC 分别是 generation、power generation / machinery、backup power 的不同 read-through。
- 这不是同质 peer set，不能直接做简单 valuation spread。后续应拆成 direct electrical / thermal infrastructure、generation / grid equipment、backup power 三条链。
- 主题验证已经不是主要 edge；下一层 edge 在 order quality、backlog conversion、margin bridge、thermal vs power mix、以及估值是否已经 price in。
- VRT 已经值得进入单股 thesis，但关键问题是订单和 margin 是否还能超过已抬高的预期，而不是继续证明它有 data-center exposure。

## Open Questions

- VRT 的 growth / margin bridge 里，volume、pricing、mix、thermal vs power、temporary cost benefit 各占多少？
- VRT backlog / orders 的质量如何：有多少来自 broad-based demand，有多少来自少数 hyperscaler / large projects？
- ETN 的 data-center orders +240% TTM 如何进入收入和 margin，Electrical Americas 的高 margin 是否可持续？
- GEV / CAT / GNRC 的 data-center power read-through 是直接 revenue driver，还是 broader power cycle / backup power proxy？
- 这个 topic 的 peer set 应该如何拆组，才不会把 electrical equipment、generation、machinery、backup power 的 driver 混在一起？
