# 固晶+耦合之外的设备段 — 竞争格局与技术路线

## 结论先行

光模块封测设备链条上，除了固晶（18.9%）和耦合（23.3%）之外，还有老三样：**引线键合（~10%）、老化/Burn-in（31.4%）、模块终测（含在 31.4%）。** 这三段在 Pluggable 时代各赚各的钱，到了 CPO 时代命运截然不同——**引线键合可能消失、模块级 Burn-in 大概率萎缩、晶圆级测试从零爆发。** 自动化整线（~15%）是贯穿全链的，壁垒最低但不会消失。

---

## 一、引线键合（Wire Bonding）

### 做什么

用比头发丝还细的金线（直径 ~25μm），把芯片上的焊盘和 PCB 的焊盘一根一根连起来。超声振动+压力→金线和铝形成合金→焊死。

### 为什么在光模块里不重要

- 光模块芯片数量少（几颗到十几颗），键合需求远不如手机/CPU（几百上千根线）
- 精度要求 ~±2μm——比固晶高但壁垒在设备本身（K&S/ASMPT 寡头），不在光模块特殊需求
- 价值量占比极低（~1%），市场小

### 竞争格局

| 公司 | 全球份额 | 定位 |
|---|---|---|
| **Kulicke & Soffa (K&S)** | ~50% | 全球 wire bonder 绝对龙头，铜线/金线全覆盖 |
| **ASMPT** | ~25% | 第二大，封装全线 |
| **Shinkawa** | ~10% | 日本，高速 bonder |

**这是典型的寡头稳定市场**——三家占了 ~85%，技术成熟，没有国产替代故事，也没有代际升级故事。光模块设备研究里完全可以跳过这一站。

### CPO 时代变化

**可能直接消失。** CPO 引擎用硅 interposer 或 Cu pillar 连接芯片，物理上不需要金线。不过即使消失也不影响投资判断——价值量太小。

---

## 二、老化测试（Burn-in）

### 做什么

做好的光模块，插到高低温箱里（-40°C ~ +85°C），通电连续跑 24-96 小时，边跑边测光功率和误码率。筛掉那些"刚出厂是好的、用两天就坏"的早期失效件。

### 为什么价值量最大（31.4%）但不性感

- 不是一台"精密设备"——是**高低温箱 + 测试平台 + 软件**的集成方案
- 单台价值量不如耦合机，但一个产线要配几十台，总量大
- 壁垒不在硬件精度——在**测试覆盖度、并行能力、温度控制、与客户流程深度绑定**

### 竞争格局（Pluggable 时代）

| 公司 | 份额 | 定位 | 上市 |
|---|---|---|---|
| **Keysight** | 主导 | 高端示波器/误码仪 + 测试平台 | ✅ KEYS US |
| **Anritsu** | 主导 | 日系，光测试仪表强 | ✅ 6754.T |
| **Chroma 致茂电子** | 中 | 台湾量测龙头，光模块 Burn-in 系统 | ✅ 2360.TW |
| **联讯仪器** | 9.9% | 国产 #1，前五唯一中国公司，覆盖 800G/1.6T | ✅ 688808 CH |
| **AEHR** | 小 | **晶圆级** Burn-in 龙头，当前光模块不是主业 | ✅ AEHR US |

Keysight + Anritsu 合计 >80%。联讯是唯一在追的中国公司，9.9% 份额但增速最快。

### CPO 时代变化——这是最大风险点

```
Pluggable 时代：
  光模块做好 → 插到 Burn-in 板 → 跑 24-96h → 合格出货
  ↑ 一个模块一个模块测

CPO 时代：
  光引擎封在交换芯片旁边 → 不能"单独老化" → 必须 wafer 级测完再集成
  ↑ Burn-in 从模块级升到晶圆级
```

| 变化 | 受益方 | 受损方 |
|---|---|---|
| 模块级 Burn-in 需求萎缩 | — | Keysight/Anritsu/联讯的传统模块 Burn-in 产品线 |
| **晶圆级 Burn-in 从零爆发** | **AEHR**（全球晶圆级龙头）、Keysight（晶圆级布局） | — |
| 1.6T 测试复杂度跳变 | Keysight/VIAVI/联讯 | — |

**Keysight 是唯一两头下注的**——模块测试有，晶圆测试也在做。所以它既有受损面又有受益面。AEHR 是纯受益方——晶圆级 Burn-in 是它的绝对主场，CPO 等于从天而降一个新市场。

## 三、模块终测（Final Test）

### 做什么

老化之后的最终质检——测误码率（BER）、眼图、光功率、光谱、协议合规（CMIS）。**这是客户验货的最后一关。**

### 竞争格局

| 公司 | 份额 | 定位 | 上市 |
|---|---|---|---|
| **Keysight** | ~40% | DCA/BERT/协议测试全平台 | ✅ KEYS US |
| **VIAVI** | ~30% | 800G/1.6T/3.2T 验证链条 | ✅ VIAV US |
| **Anritsu** | ~15% | 日系，光测试强 | ✅ 6754.T |
| **联讯仪器** | ~10% | 国产 #1，ATE + DCA | ✅ 688808 CH |

海外三家 >80%，联讯是唯一国产替代方向。和 Burn-in 不同——终测在 CPO 时代不会被消灭，CPO 引擎集成之后还是要测 BER 和眼图。但测试方式从"模块级"变成"引擎级+系统级"。

---

## 四、自动化整线

### 做什么

把单台设备（固晶机、耦合机、测试柜）用机械手、传送带、软件串成可复制的量产产线。

### 为什么壁垒最低

- "会做自动化 ≠ 能吃到光模块核心利润池"
- 3C 自动化公司都能做搬运/上下料，但精度到微米级的**设备**才是壁垒
- 罗博特科和博众精工在这段有布局，但核心估值锚是 ficontTEC 的耦合，不是整线

### CPO 时代变化

**不消失，但地位不变。** 产线永远需要自动化。只是自动化整线赚的是"搬运"的钱，不是"精度"的钱。

## 五、CPO 时代的设备价值迁移总图

```
                    Pluggable 时代           →    CPO 时代
  ┌─────────────────────────────────────────────────────────┐
  │ 固晶      18.9%  稳中略涨          → 精度翻倍，ASP 涨  │
  │ 耦合      23.3%  ↑↑ 暴涨          → 端口数 4-16x 跳升  │
  │ 引线键合   ~1%    → 消失            → 物理上不需要了    │
  │ 模块 Burn-in  ~15% → 萎缩           → 被晶圆级替代      │
  │ 模块终测   ~10%   → 转型            → 引擎级+系统级测   │
  │ 晶圆级测试  ~0%    → **从零爆发**    → CPO 创造的新品类  │
  │ 自动化整线  ~15%   → 不变            → 永远需要          │
  └─────────────────────────────────────────────────────────┘
```

**最大受益**：耦合（全部）、固晶（高端段）、晶圆级测试（全新）
**最大受损**：模块级 Burn-in、引线键合
**转型存活**：模块终测（Keysight/VIAVI/联讯）
