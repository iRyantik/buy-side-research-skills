# 光模块设备行业 — 完整研究 Workflow

> 从零基础到分场景 L/S 排序，5 步走完一个行业从陌生到能下判断。
> 每个步骤 ≈ 1-3 轮对话 + 10-30 分钟。

---

## 流程概览

```
Step 1: teach-in          → 光模块是什么？怎么造的？设备链条在哪？
Step 2: industry-landscape → 行业全景、价值池 51.8B、17 家公司
Step 3: mechanism-insight  → 固晶/耦合竞争格局深挖、CPO 时代谁受益
Step 4: candidate-screener → 分 3 个 regime 做 L/S 排序（最核心步骤）
Step 5: scenario-model     → CPO>15% 场景下量化测算每个理论回报
```

## 关键决策路径

这个 workflow 里有三个转向点是 AI 最有价值的：

1. **Step 1→2**：看完 teach-in 后，研究员意识到"利润不在模块厂、在设备端"——研究聚焦到设备而非模块
2. **Step 3→4**：看完竞争格局后，研究员问"CPO 时代这些公司排序会怎么变"——触发了 candidate-screener 的分场景框架
3. **Step 4→5**：排序表里 AEHR 标了"小赌注"，研究员要求量化——触发了 scenario-model

---

## 关于这个 example

- 公司名和股票代码是真实的，估值为 2026-06-01 快照
- 这个 workflow 花了约 2-3 小时（含人工判断），AI 完成了 80% 的数据收集和初稿
- 研究员的核心时间花在：判断 regime 概率、确认 CPO 路线分歧、审查 source 质量
