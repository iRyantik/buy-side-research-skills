# Examples — 跟着学

本目录是 buy-side-research-skills 的示例仓库。每个子目录是一个完整的研究 workflow，包含对话记录、AI 产出物和研究笔记。

---

## 如何阅读

每个 example 包含三类内容：

| 标记 | 含义 |
|---|---|
| **🗣 问** | 研究员问了什么、为什么这么问 |
| **🤖 答** | AI 回了什么（关键摘录，非全文） |
| **📝 笔记** | 哪一步改变了方向、AI 在哪最有用、踩了什么坑 |

---

## 光模块设备行业研究

> 从零开始到分场景 L/S 排序的完整 workflow。最推荐的入门 example。

**流程**：

1. [建立物理直觉](optical-module-equipment/01-teach-in.md) — teach-in 了解光模块是什么
2. [行业全景](optical-module-equipment/02-industry-landscape.md) — industry-landscape 看价值池和竞争格局
3. [深挖竞争](optical-module-equipment/03-mechanism-insight.md) — mechanism-insight 拆固晶和耦合竞争
4. [分场景排序](optical-module-equipment/04-candidate-screener.md) — candidate-screener L/S 场景推票
5. [场景测算](optical-module-equipment/05-scenario-model.md) — scenario-model 量化"CPO>15% 谁受益"

## 自己怎么用

1. 安装插件后，打开一个空 workspace
2. 按 example 里的对话流程，用自己的行业/公司替换关键词
3. 对比 example 的产出看 AI 做对了什么、漏了什么
4. 每个 example 的"笔记"部分是研究员视角——最值得读
