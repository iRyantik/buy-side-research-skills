# actuals-resolved.json Data Catalog

> This is the English translation of [actuals-data-catalog.md](./actuals-data-catalog.md). The Chinese version is the source of truth.
>
> This file is the field catalog for `_cache/financial-data/internal/actuals-resolved.json`.
> Skills consuming actuals reference this file in their appendix. Agents can use it to determine
> what data is available without opening the JSON.
> Generated by `/financial-data`. Field presence depends on provider coverage and company disclosure.

## Top-Level Structure

```
actuals-resolved.json
├── meta                    # Metadata
├── market_data             # Market snapshot (Bridge/yfinance/WebSearch degradation chain)
├── statements              # Three statements + optional revenue_split
│   ├── income_statement
│   ├── balance_sheet
│   └── cash_flow
├── segments                # Segment data (if available)
├── supplementary           # Elastic KPIs (collected by business model)
└── source_map              # Provenance passthrough (consuming skills use these labels, not [actuals])
```

## 6. source_map

> Consuming skills read this field to map data fields to specific [S#](url) / [I#] labels — not writing [actuals].
> Each entry contains `source_layer`, `url`, `detail`, `label`.

```json
"source_map": {
  "S_1": {"source_layer": "official_web", "url": "https://...Q1-results.pdf", "detail": "Q1 Results PDF p3", "label": "S1"},
  "I_1": {"source_layer": "yfinance", "url": null, "detail": "yfinance quote", "label": "I1"}
}
```

## 7. Usage Rules for Consuming Skills

1. **Read actuals-resolved.json first, then source_map** — use source_map labels ([S1]/[I1]), not [actuals].
2. **actuals-only ratio rule**: all ratio inputs must have real values in actuals. Do not use FY20XXE / consensus / forward estimates in calculations.
3. **Missing fields: skip silently**: if an input is missing → that ratio is not output. Do not mark [NOT DISCLOSED], do not occupy a row.
4. **Period labels**: must read actuals' real period labels. Do not rewrite HK H1 as Q2.
5. **Segment profit methodology**: use the same profit metric for segments and consolidated. Note the methodology change if you switch.
