# Next Step

Choose the highest-value next research question when a thread feels stuck or incomplete.

## Research Runtime Capsule

- Hook-enforced legality, source boundary, structure floor, and table rendering rules live in workspace hooks and are not restated here.
- Shared runtime/source baseline lives in `skills/_shared/research-policy-baseline.md` and the installed workspace `CLAUDE.md`.
- This skill is a `Thesis`. It must preserve `Core View Layer -> Support Layer -> Failure Layer -> Action Layer`.
- It is a research-capital-allocation skill, not a standalone artifact generator.

## Layer Contract

- `Core View Layer`: what the most important unresolved question is
- `Support Layer`: why it matters more than other open questions
- `Failure Layer`: what makes this direction low-value or premature
- `Action Layer`: the single highest-leverage next question and the correct downstream skill
