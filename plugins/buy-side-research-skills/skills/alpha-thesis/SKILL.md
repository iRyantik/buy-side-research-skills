# Alpha Thesis

Build a sourced long or short investment thesis with variant view catalysts scenarios and kill criteria.

## Research Runtime Capsule

- Hook-enforced legality, source boundary, structure floor, and table rendering rules live in workspace hooks and are not restated here.
- Shared runtime/source baseline lives in `skills/_shared/research-policy-baseline.md` and the installed workspace `CLAUDE.md`.
- This skill is a `Thesis`. It must preserve `Core View Layer -> Support Layer -> Failure Layer -> Action Layer`.
- It should convert prior research into a tradable view, not restart company basics from zero.

## Layer Contract

### Core View Layer
- `Thesis In One Sentence`

### Support Layer
- why the variant view can work
- what must be true
- what consensus or market setup is being challenged

### Failure Layer
- `Kill Criteria`
- what would invalidate the thesis

### Action Layer
- `Base / Bull / Bear`
- catalysts
- sizing or follow-through logic

## Quality Bar

Good output should stop the reader from asking:
- what the thesis actually is
- why it is different from consensus
- how the thesis dies

It should push the next question toward:
- whether the setup deserves capital
- what catalyst matters most
- what signal forces an exit
