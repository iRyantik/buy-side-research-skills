# Tech Manufacturing（技术制造）— KPI 模板

适用：半导体设备、电池、光伏、3D 打印、先进封装

## 弹性指标

| KPI | 中文搜索 | English | 日本語 | 怎么查 |
|---|---|---|---|---|
| **Technology Node / Precision** | 制程节点 / 精度 | technology node / precision | 技術ノード / 精度 | 产品 spec、IR |
| **Yield** | 良率 | yield rate | 歩留まり率 | IR、管理层 commentary |
| **Capacity (wafer/module/month)** | 产能 | production capacity | 生産能力 | IR |
| **Capacity Ramp Progress** | 产能爬坡 | capacity ramp progress | 生産能力立上げ進捗 | IR |
| **Cost per Unit / WPH** | 单位成本 | cost per wafer / unit | 単位コスト | IR、行业数据 |
| **Tool Installed Count** | 装机台数 | tool count / installed units | 設置台数 | IR segment |
| **Equipment ASP** | 设备单价 | equipment ASP | 装置単価 | IR、产品发布 |

## Red Flags

- Yield 持续下降 → process 问题或新节点 ramp 不顺利
- Capacity ramp 慢于 guidance → 需求不达预期
- 技术节点被竞争对手追上 → moat erosion
