# Nuclear - 行业 KPI 模板

## 行业边界

本模板覆盖**核能产业链**的所有上市玩家：

- **运营核电的 Utility / IPP**：Constellation Energy、Vistra（含 Comanche Peak）、Public Service Enterprise (PSEG)、Duke Energy、Dominion、Southern Company（部分）、TVA (政府)
- **SMR (Small Modular Reactor) Developers**：NuScale（上市）、Holtec、Oklo（上市）、X-Energy（private）、TerraPower（private 但 Bill Gates 参与）；ASTM Power
- **Fuel Cycle**：Cameco（铀矿+转化+浓缩）、Centrus Energy（HALEU 浓缩）、UEC (Uranium Energy Corp)、Energy Fuels、Denison
- **Uranium Pure-Play Miners**：Cameco（最大、稳定）、Paladin、UEC、Boss Energy、Encore Energy、Yellow Cake (PLC)
- **Reactor Manufacturers / Engineering**：BWXT（Naval reactor + 商业 SMR）、Westinghouse（Brookfield + Cameco 合资，private）、GE Hitachi (BWRX-300, private)、Doosan
- **Subsystem Suppliers**：Curtiss-Wright（valves、reactor coolant pumps）、Mirion Technologies、Ultragenyx
- **Adjacent Tech**：Energy Fuels（vanadium、rare earth 副产品）

不在本模板：
- 全 utility（火电主导，nuclear 占比 < 30%）→ 用 utility 一般框架，把 nuclear 当 segment
- 中国核电（中广核、中核）→ 中国市场监管 / 估值框架不同

## 当前 regime 的典型变量（市场在 trade 什么）

**当前主流叙事（2024-2026）**：
- **AI / Datacenter 电力 demand 推动**：hyperscaler 直接签 PPA（Microsoft + Constellation Three Mile Island、Amazon + Talen、Oracle + Constellation 等）
- **Nuclear renaissance**：政府 IRA 45U PTC（每 MWh ~$15）支持现存核电；ADVANCE Act 加速 SMR 许可
- **铀价上行 cycle**：U3O8 spot price 从 2020 年 $30 涨到 2024 年 $80-100+，结构性供给短缺
- **SMR 商业化预期**：FOAK（First-of-a-Kind）项目从 2030 推迟到 2030+；NuScale 2024 年 cancel 旗舰项目导致 SMR thesis 重估
- **HALEU (High-Assay Low-Enriched Uranium) 短缺**：SMR 燃料几乎全部依赖俄罗斯，DOE 资助本土能力（Centrus 受益）
- **Public 接受度变化**：Nuclear 民调支持率从 30% 升到 50%+（IRA 时代）

## 核心 KPI（按子板块）

### Utility / IPP 运营核电

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| Nuclear Capacity (MW) | 运营核电装机容量 | Constellation 22 GW（最大）、Vistra 6.4 GW |
| Capacity Factor | 实际发电 / 理论发电 | 美国核电 typical 90%+，世界级；< 88% 警惕 unplanned outage |
| 平均剩余许可期限 | NRC license 剩余年数 | 60 年 vs 80 年 license extension（关键估值变量） |
| PPA Coverage | 已签 PPA / 总发电量 | Hyperscaler 直接 PPA 是当前主题 |
| 平均 PPA Price ($/MWh) | 加权 PPA 价格 | 2024 后新签 PPA 远超 historical（$70-100/MWh vs $30-50） |
| Refueling Cycle Cost | 换料周期成本 | 18-24 月一次，单次 $50-200M |
| 45U Production Tax Credit 收益 | IRA 提供的核电 PTC | 价值 ~$15/MWh（约相当于 capacity factor）；2024-2032 valid |
| Forward Capacity 销售 (PJM、NYISO) | Capacity market 收入 | 容量市场 clearing price 是另一收入来源 |
| Decommissioning Trust Funding | 退役基金满足度 | < 90% 是 future liability 风险 |

### SMR Developers (基本是 pre-revenue 阶段)

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| Cash Burn Rate / Quarterly | 季度烧钱速度 | 决定 runway 长度 |
| Cash Position + Liquidity | 现金 + 流动性 | NuScale 在 2024 取消项目后 cash 是关键存活 |
| NRC Licensing Milestone | 美国核管会许可进度 | NuScale: SMR-Design Approval (2020)；后续 Construction Operating License |
| Customer Pipeline | 已签 customer agreements | 区分 LOI (非约束) vs Firm Order；多数仍是 LOI |
| First-of-a-Kind (FOAK) Cost | 首座 SMR 总成本 | NuScale UAMPS 项目原 $5.3B → cancel 时 $9.3B（暴雷信号） |
| Cost Reduction Pathway | Nth-of-a-kind cost trajectory | 行业目标：FOAK $4-6B → NOAK $2-3B per unit |
| Government Funding Secured | DOE / DoD 资助金额 | NuScale、Oklo、Holtec 都依赖 ARDP / Loan Programs Office |
| Regulatory Path | NRC vs DoD pathway | DoD 路径（Project Pele）更快但应用受限 |

### Fuel Cycle (Cameco、Centrus、其他)

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| **Cameco 特有** |  |  |
| McArthur River 产量 | 全球最大铀矿之一 | 复产后产量是关键 |
| Cigar Lake 产量 | 第二大铀矿 | 同上 |
| Long-term Contract Book | 已签长期合同总价值 | Cameco 战略：长期合同 + 现货 mix |
| 平均合同 floor price | 长期合同最低保证价 | 历史 floor $30-40，新合同 $60-80 |
| **Centrus 特有** |  |  |
| HALEU production capacity | 高丰度低浓缩铀产能 | 2024 启动首批 deliveries to DOE |
| LEU (low-enriched) Long-term Contracts | 传统燃料合同 | 仍是主收入来源 |

### Uranium Miners (UEC, Boss Energy 等)

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| ProductIon Capacity (lbs U3O8 per year) | 设计产能 | 行业 typical 1-5M lbs |
| Reserves & Resources (M&I + Inferred) | 储量 | 决定 mine life |
| Cash Cost ($/lb U3O8) | 单位生产成本 | < $35/lb 优秀，> $50 警戒 |
| Production vs Capacity ramp | 实际产量爬坡 | 多数 junior miner 落后 plan |
| Long-term Contract Coverage | 已签合同的产量比例 | 影响价格暴露 |
| Sensitivity to U3O8 spot price | 对铀价的杠杆 | 纯 spot exposure vs 合同混合 |

### Reactor / Subsystem Suppliers

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| Naval Reactor Backlog | 海军核反应堆订单 | BWXT 是美国唯一 naval reactor 供应商 |
| 商业核反应堆订单 | 民用反应堆收入 | 当前 SMR 阶段：订单零星 |
| Nuclear segment 占公司比例 | Nuclear 占总收入 | 决定 thesis pure-play 程度 |
| Long-term contract structure | 海军 multi-year vs 短期民用 | DoD 合同有 visibility |

## 行业特定实证驱动因素

**Utility 核电运营**：
- 季度发电量 + capacity factor
- 新签 PPA 公告（特别是 hyperscaler 大单，2024 后 hot 点）
- License extension 决定（60 → 80 年）
- 45U PTC IRS 实施细则（影响 cash flow timing）

**SMR Developers**：
- NRC licensing milestones
- 客户 firm orders（非 LOI）
- DOE / DoD funding announcement
- FOAK project 成本 / 进度公告（NuScale 项目取消是 disaster）

**Fuel Cycle / Miners**：
- U3O8 spot price (UxC、TradeTech weekly)
- 长期合同价（lagging spot 6-12 月）
- 中国 / 印度核电建设 announcement
- 主要供应中断（Niger 政变、Cigar Lake / McArthur River disruption）
- DOE HALEU 拨款 announcement

**Reactor Suppliers**：
- 美国海军预算（BWXT）
- 商业新建 reactor 订单（Vogtle 完工后 next 项目）

## 典型估值锚点

| 子板块 | 估值方法 | 注意事项 |
|---|---|---|
| Utility 含核电 segment | SOTP（Nuclear MWh × forward power price 估值） | Nuclear 资产 typical $1500-3000/kW 估值 |
| Pure Nuclear IPP (Constellation, Vistra-nuclear) | EV/EBITDA、FCF yield、$/kW | 当前 multiples 显著高于传统 utility |
| SMR Developers | Cash position + option value + pilot pipeline | 类似 early-stage tech，无传统估值 |
| Cameco | EV/EBITDA、NAV (基于 forward U3O8)、P/CFPS | 周期性 + 长期合同 lock-in |
| Junior Uranium Miners | NAV、$/lb U3O8 in resource | 高 leverage to U3O8 price |
| Centrus | EV/EBITDA、option value（HALEU 商业化） | 转型期估值 |
| BWXT | EV/EBITDA、SOTP（Naval vs Commercial） | Naval 部分溢价 |

## Cross-cut 注意事项（这个行业最容易翻车的地方）

### "Nuclear" 在 Utility Reporting 的口径

- 大多数 utility 不单独披露 nuclear segment economics
- Constellation 是 pure-play exception；Vistra 通过 acquisition (Energy Harbor) 扩 nuclear
- 横向比较时如果某 utility 只 report combined generation，需要 estimate nuclear contribution

### 45U PTC 的影响

- 2024-2032 valid，提供 ~$15/MWh PTC（如 wholesale price < $43.75/MWh）
- 这个 PTC 对 cash flow 的影响 = 现存核电估值上修的核心驱动
- 但 PTC 是 phase-in 制度，新签 PPA 可能"吃掉"PTC 价值
- 横向比较 EBITDA 时要明确：含 / 不含 PTC

### Hyperscaler PPA 的真实经济性

- 2024 年最大新闻：Microsoft + Three Mile Island、Amazon + Talen、Oracle + Constellation
- 但 PPA 价格细节多数未披露
- 一些 PPA 包含 "additional capacity" (重启 / 新建 SMR)，不仅是现存机组
- 横向比较 PPA value 时要注意：是 standalone existing capacity 还是 capacity expansion

### SMR 商业化 Timeline 极不确定

- NuScale 2024 取消 UAMPS FOAK 项目（成本上涨太快）
- 当前最早 SMR FOAK ~2028-2030（如 Oklo Aurora、X-Energy with Dow）
- 大规模 deployment（NOAK）2035+
- 对 SMR pure-play 公司估值高度依赖 timeline assumption
- 不要假设 "SMR 是确定 thesis"——历史上 nuclear 项目 90%+ delay

### HALEU 供给瓶颈

- SMR 燃料 (HALEU) 历史上几乎全部俄罗斯供应（TENEX）
- Russia ban 后美国本土能力 = Centrus（唯一）
- DOE 拨款逐步建立国内 supply chain
- SMR 商业化进度受 HALEU 供给约束（即使技术 ready）
- 横向比较 SMR developers 时要看：HALEU 来源 confirmed 否

### 铀价的"两层结构"

- **Spot price**：U3O8 现货，UxC / TradeTech 报价，volatile
- **Long-term contract price**：utility 实际采购价，lag spot 6-12 月
- Cameco 等大供应商主要靠 long-term contracts
- Junior miners 多数对 spot 完全 exposed
- 横向比较时区分两种价格暴露

### Nuclear "Renaissance" 历史 Base Rate

- 2010 年前后也有过 "Nuclear Renaissance" 叙事（Vogtle、Summer 项目）
- Vogtle Units 3-4：原计划 2017 完工 / $14B 预算 → 实际 2023-2024 完工 / $35B
- Summer Units 2-3 abandon（SCANA 破产）
- Fukushima (2011) 终结上一轮 renaissance
- 当前 cycle 是否会重演历史？哪些公司最 exposed?

### Decommissioning Liability

- 核电 retirement 后退役成本巨大（$1-3B per reactor）
- Utility 维持 Decommissioning Trust Fund
- 但 trust fund underfunded 是常见问题
- 横向比较 nuclear utility 时要看 trust funding ratio

### "Pure Nuclear Play" 实际定义

- Constellation 是当前最 pure 的 listed nuclear utility
- Vistra 部分（Comanche Peak）但同时有 gas、coal、solar
- Pure SMR 公司多数还在 pre-revenue
- 矿业公司（Cameco）是 commodity proxy 而非 nuclear 运营 proxy
- 横向比较时要区分 thesis：是 nuclear power thesis 还是 uranium price thesis？这是两件事
