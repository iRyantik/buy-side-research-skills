# EPC (Engineering, Procurement, Construction) - 行业 KPI 模板

## 行业边界

本模板覆盖：
- **大型 Infrastructure EPC**：Fluor、Jacobs、AECOM、WSP、KBR、Stantec
- **Energy / LNG EPC**：Bechtel (private)、McDermott、Saipem、Subsea7、TechnipFMC、Petrofac、JGC、Chiyoda
- **Specialty Contractors**：Quanta Services、MasTec、MYR Group、Granite Construction（这些更接近 utility / heavy civil contractor）
- **Mining EPC**：Worley、Hatch (private)、Wood Group
- **Process / Chemical EPC**：Linde Engineering、Air Products engineering
- **Power & Renewable EPC**：MasTec Renewables、Quanta、Sterling Infrastructure
- **数据中心 EPC**：DPR Construction (private)、Holder (private)、Turner、Skanska USA

不在本模板：
- Pure consulting (无 construction execution) → 接近 Professional Services
- Architects / Designers without execution → 同上
- Real estate developers → Real Estate 框架

## 当前 regime 的典型变量（市场在 trade 什么）

**当前主流叙事**：
- AI 数据中心建设 super-cycle：hyperscaler capex（Microsoft、Google、Meta、Amazon、Oracle）驱动 EPC 订单
- LNG 出口扩张：US LNG 第二波（Plaquemines、Rio Grande、Port Arthur Phase 2）
- 能源转型 capex：renewable 项目、grid upgrade、transmission build-out
- IRA / IIJA / CHIPS 政府资金落地速度
- 中东 mega projects（NEOM、PIF projects）
- 项目执行风险卷土重来（COVID 后通胀 + 劳动力 + 供应链）

## 核心 KPI

### 通用 EPC KPI

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| Total Backlog | 在手项目总价值 | 关键 visibility 指标 |
| Backlog / LTM revenue | Backlog 覆盖率（年） | 1.5-3 年 typical；< 1 年警戒 |
| Book-to-bill | 新签 / 收入 | > 1.0 增长，持续 < 0.9 警戒 |
| Backlog 质量 (margin profile) | Backlog 中的 margin 分布 | 不同 vintage 项目 margin 差异大 |
| Project mix（规模、类型） | 项目结构 | Mega projects (>$1B) 风险更大但 margin 也可能更高 |
| Backlog by 合同类型 | Fixed-price / Cost-plus / Reimbursable / GMP 占比 | 关键风险结构指标 |

### 合同结构（关键）

| 合同类型 | 风险归属 | EPC 利润率 typical |
|---|---|---|
| **Cost-plus / Reimbursable** | 客户承担成本风险 | 5-8%，稳定但低 |
| **Fixed-Price / Lump-Sum Turnkey (LSTK)** | EPC 承担成本风险 | 7-12% 上限，但有 cost overrun 风险（可能负） |
| **Guaranteed Maximum Price (GMP)** | 共担 | 8-10% |
| **Time and Materials (T&M)** | 客户承担 | 5-7%，类似 cost-plus |

横向比较 margin 时必须看合同结构 mix，不能直接比 EBIT margin。

### 项目执行风险

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| Cost overrun 历史 | 过去 5 年 fixed-price 项目超支幅度 | 每个 EPC 公司都有 disaster project history（Bechtel、McDermott、Fluor 都有） |
| Project charges (write-down) per quarter | 单季度项目减值 | 重大 charge ($100M+) 是 thesis 风险信号 |
| Joint Venture 占比 | 与其他 EPC 合资项目 | 共担风险 + 共担利润；执行复杂度高 |
| Specific project milestone progress | Key project 进度 (% complete) | 决定是否会引发 charge |

### 现金流 / 工作资金

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| Working Capital cycle (DSO + DIO - DPO) | 营运资本周期 | EPC 项目 milestone billing，cash 是关键 |
| Operating CF / EBITDA | 现金质量 | < 70% 警惕 |
| Net Debt / EBITDA | 杠杆 | EPC 公司 typical < 2x（cash-flow 公司） |
| 客户预付款 vs 应收账款 | Working capital 平衡 | 大型项目客户预付款是关键 |

### 客户与地理结构

| KPI | 含义 | 警戒阈值 / 解读 |
|---|---|---|
| 客户集中度 | Top 5 / Top 10 客户占比 | 高集中度 = idiosyncratic 风险 |
| Government vs Private 占比 | 客户类型 | 政府客户更稳但毛利低 |
| 地区分布 | 美国 / 欧洲 / 中东 / 亚洲 | 中东 mega project 利润高但 collection 风险 |
| 行业 mix（Energy / Infrastructure / Power / Mining / 等） | 终端市场 | 决定周期暴露 |

## 行业特定实证驱动因素（股价跟着什么动）

- **重大新订单 announcement**：超过 $1B 的项目签约
- **季度 project charge 公告**：EPC 公司"earnings disaster"通常来自单个项目暴雷
- **客户 capex announcement**：大型客户（hyperscaler、LNG 业主、矿企）capex 周期决定 EPC 上行
- **Final Investment Decision (FID)**：客户对大项目的最终投资决定
- **政策事件**：IRA / IIJA 资金 disbursement、permitting 改革
- **大宗商品价格**：油价高 → upstream EPC 订单；矿价高 → mining EPC 订单

## 典型估值锚点

| 子板块 | 估值方法 | 典型区间 |
|---|---|---|
| 大型 Infra EPC | EV/EBITDA、P/E、FCF yield | EV/EBITDA 8-13x（earnings 波动大要看 normalized） |
| Energy EPC | EV/EBITDA、P/E (cyclical) | 周期性强，10-15x mid-cycle |
| Specialty Contractors (Quanta、MasTec) | EV/EBITDA、P/E | 12-18x（visibility 较好的偏溢价） |
| Mining EPC (Worley) | EV/EBITDA、P/E | 6-10x（mining cycle 压制） |

## Cross-cut 注意事项（这个行业最容易翻车的地方）

### Backlog 质量比 Backlog 数量重要

- **Marginally profitable 项目**会进 backlog 但贡献 0 或负 margin
- 历史案例：McDermott 的 LNG 项目（2018-2020）、Fluor 的 fixed-price 项目（多年）、Saipem
- 横向比较 backlog 时要追问：什么 vintage？什么合同结构？
- 单纯比"backlog 多寡"是误导

### Fixed-Price 项目暴雷模式

- 行业 boom 期，公司为抢单接受激进 fixed-price → 后续通胀 / 供应链 / 劳动力问题 → 巨额 charge
- 当前 regime 警告：LNG 第二波 + 数据中心 boom → 是否再次 over-aggressive bidding?
- 横向比较 margin 时要看 fixed-price 占比和近期 charge 历史

### Quarterly Earnings Volatility

- EPC 季度收入受 project milestone 触发
- 大项目接近完工 / 启动 / 交付 → 单季度收入 30-50% 波动正常
- 不要从单季度 trend 推断公司基本面变化
- 看 TTM / 年化 trend 才有意义

### Client Concentration vs Diversification 取舍

- 高集中度（如某 EPC 70% 收入来自 1-2 个客户）= 单点失败风险
- 但分散 client 通常意味着小项目占比高、margin 低
- Best-in-class 是"diversified across mega-projects"
- 横向比较时要 normalize to project size

### "Mega Project" 风险溢价

- 单项目 > $5B 的项目失败可吞噬一年盈利
- McDermott 2020 破产很大程度上由 LNG mega project 引发
- 接受 mega project 的 EPC 公司应该有 outsized margin 补偿，否则 risk-reward 失衡

### JV 项目的真实 economics

- EPC 公司常通过 JV 分担风险但也分摊利润
- Reported revenue 可能含 100% project value（pro-rata），实际 economic interest 是 50%
- 横向比较时确认 reporting 口径

### Renewable / Data Center EPC 的特殊性

- Quanta、MasTec 等的 renewables / utility 业务 visibility 高于 traditional EPC
- 但 margin 受劳动力短缺压制
- 数据中心 EPC（Turner、DPR private）多数是 private，public proxies 有限

### 现金流 vs Earnings 的脱节

- Project milestone billing → 收入确认与 cash collection 时间错位
- 一些 EPC 公司报告 strong earnings 但 cash flow 持续弱
- 横向 cross-check：Operating CF / Net Income 持续 < 0.7 = 警告

### 政府客户的支付风险

- 中东、非洲、东南亚某些政府项目 collection 周期 12+ 个月
- Force majeure / contract dispute 在某些区域是常态
- "Reported revenue" 可能远超实际 collected cash

### 行业周期识别

- EPC 是高度 cyclical：Boom（2008-2014 油气、2024- AI/LNG）→ Bust（2015-2020 油气）
- 在 boom 顶部（high backlog、high book-to-bill、激进 bid）做多 EPC = 经典反向风险
- 行业 base rate：每个 boom 后期都会有 1-2 家头部 EPC 出现 mega project 暴雷
