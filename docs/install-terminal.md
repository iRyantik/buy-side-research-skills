# Buy-Side Research Skills — 安装指南（Terminal 版）

你是 Claude Code agent。CC Terminal 用户直接用内置命令安装。

---

## Step 1: 安装插件

```
/plugin marketplace add iRyantik/buy-side-research-skills
/plugin install buy-side-research-skills
```

成功后按 `/` 搜 `stock-quickread`。看不到 → 重启 CC。

## Step 2: 初始化 workspace

新建文件夹 → CC 打开 → `/init-workspace`

---

各 skill 额外依赖（ffmpeg、whisper 等）首次使用时自动安装。
