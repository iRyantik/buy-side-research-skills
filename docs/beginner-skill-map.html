Layer Map

五层分层图

从上到下看，你会更容易理解：哪些 skill 是准备动作，哪些 skill 是研究入口，哪些 skill 只在问题已经明确时才值得调用。

Operations

先把环境、session 和材料准备好

这一层不是研究结论，而是把 workspace、原始材料和结构化数据准备到位。

init-workspace

第一次用插件时，先把 research workspace 骨架搭起来。

先用

new-session

开始研究一个新公司、新行业或新主题时，先建 topic 容器。

高频入口

ingest

你手上已经有 PDF、Excel、PPT 时，把它们转成可搜索文本。

financial-data

需要结构化三表或披露数据时，先把基础数据拉出来。

Triage

先做 first-pass，不要一开始就深挖

这一层最适合 beginner。目标不是“研究完”，而是先判断值不值得继续投入时间。

stock-quickread

你想先快速看懂一家公司值不值得继续研究时，用它起手。

公司入口

industry-quickread

你对一个陌生行业或主题没概念时，先用它抓 current regime 和价值链。

行业入口

information-impact

你想判断一条新闻、传闻或 note 靠不靠谱、值不值得追时，用它。

candidate-screener

你已经有一个主题，想系统找受益股或受损股时，用它筛候选。

next-step

你卡住了，不知道下一步问什么、查什么时，用它重新路由。

Foundation

先把基础框架搭对，再谈 thesis 或估值

这一层的作用是把公司、行业机制、市场预期和 driver 框架理顺，避免直接跳进结论。

company-primer

当你需要系统理解公司卖什么、客户是谁、披露口径怎么演变时，用它。

consensus-map

当你想知道市场现在到底信什么、priced-in 什么时，先摊开预期栈。

推荐升级

mechanism-map

行业机制、工程原理或设备链条没搞懂时，先别急着建模。

driver-map

收入、利润、price-volume-mix 或 backlog 驱动没拆开时，先用它。

推荐升级

cross-market-compare

同一家公司有 A/H、ADR 或跨市场对标时，用它做口径和估值归一化。

Deep-Work

问题明确以后，再进入深度研究或建模

这一层适合你已经知道自己要验证什么、反驳什么、或者要把观点沉淀成模型与 thesis 的时候。

peer-deep-dive

想横向比较几家公司、看谁更值得继续研究时，用它。

primary-research-plan

当你需要 expert call、channel check 或 survey 设计时，用它做合规研究计划。

alpha-thesis

当 variant view 已经成形，准备写做多/做空逻辑时，用它收束成 thesis。

bear-pre-mortem

想把自己的 thesis 反打一遍，找最大漏洞和 kill criteria 时，用它。

earnings-setup

财报前后你想抓关键变量、预期差和读数框架时，用它。

pair-trade

同时比较 long/short 两边，判断 spread logic 是否站得住时，用它。

3-statement-model

准备把经营假设落到三表模型时，用它起 operating model。

dcf-model

需要 DCF 或 reverse DCF，判断隐含假设和内在价值时，用它。

comps-analysis

需要 peer multiples、相对估值和市场框架对照时，用它。

model-update

已有模型遇到新财报、新指引或新假设时，用它刷新。

提醒：`deep-work` 不是默认入口。没有明确问题时，先回到 `triage` 或 `foundation`。
Memory

把 earned insight 沉淀下来

研究不是“做完就丢”，而是要把真正有价值的判断沉淀成下次能直接复用的记忆层。

research-journal

当你已经有一轮研究发现，想沉淀 topic journal 和 Boss Brief 时，用它收尾。

推荐收尾
Starter Paths

常见起手路线

你不需要每次都从头设计 workflow。下面这几条路线，基本覆盖 beginner 最常见的使用场景。

看一家公司值不值得继续研究

适合第一次接触单一公司，目标是先形成“值不值得深挖”的判断。

new-session stock-quickread driver-map research-journal

先看一个陌生行业或主题

适合你还没有锁定公司，先想看清 regime、value chain 和关键 KPI。

new-session industry-quickread mechanism-map candidate-screener

从文件和数据起步

适合你已经有 PDF、Excel 或想直接拿结构化财务数据开始搭模型。

ingest financial-data driver-map 3-statement-model

准备写 thesis 或做反驳

适合你已经看过公司和预期框架，准备把观点收束成 actionable thesis。

consensus-map alpha-thesis bear-pre-mortem research-journal
Skill Picker

按任务找 skill

点一个任务场景，页面会高亮最相关的 skill 节点和路径。适合 beginner 在“不知道该用哪个 skill”时快速定位。

当前模式：全部。你会看到完整分层图和推荐主线。

看公司

推荐顺序：`new-session` → `stock-quickread` → `driver-map` → `consensus-map` → `alpha-thesis`。

看行业

推荐顺序：`new-session` → `industry-quickread` → `mechanism-map` → `peer-deep-dive`。

看新闻

推荐顺序：`information-impact` → `candidate-screener` → `stock-quickread` 或 `consensus-map`。

建模

推荐顺序：`financial-data` → `driver-map` → `3-statement-model` → `dcf-model` / `comps-analysis`。

写 thesis

推荐顺序：`consensus-map` → `alpha-thesis` → `bear-pre-mortem` → `research-journal`。

如果你依然不确定，就直接回到 `next-step`。它本身就是给“研究卡住了”的路由器。
